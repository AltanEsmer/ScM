Define best_itinerary(data). Input data is a dictionary with flights, start, goal, and time. flights is a list of at most 12 flights [origin, destination, departure, arrival]; origin and destination, start, and goal are ASCII city strings, and departure, arrival, and time are integers with departure < arrival for every flight. A route starts in start with its first departure >= time; each subsequent flight has origin equal to the previous destination and departure >= the previous arrival. The last destination must equal goal. Waiting and repeated cities are allowed. Rank routes by earliest final arrival, then fewest flights, then lexicographically smallest sequence of original zero-based flight indices in travel order. If start == goal return []; otherwise return the best route as a list of original zero-based flight indices in travel order, or None if no route exists. Do not modify the input.

Return only Python 3.12 code using the standard library. Define the requested function. Do not include Markdown fences, explanations, tests, or executable input/output code.
