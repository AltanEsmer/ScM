Define min_resource_route(data). The JSON object data has n, edges, start, goal, budget, and required. There are n vertices numbered 0 through n-1, with 1 <= n <= 16. edges has at most 60 entries, each [u, v, resource, cost], describing a directed edge. resource is an integer from 1 through 8 and cost is an integer from -10 through 20. Parallel edges and self-loops are allowed. start and goal are vertices. budget is an integer from 0 through 80. required is a sorted list of at most five distinct vertices.

Consider walks starting at start, ending at goal, and visiting every required vertex. The starting vertex counts as visited. Vertices and edges may be repeated. The sum of resource over all edge occurrences must be at most budget. The total cost is the sum of cost over those occurrences and may be negative. An empty walk is allowed when start equals goal and all required vertices are already visited. Return the minimum total cost as an integer, or None if no such walk exists. Do not mutate data.

Return only Python 3.12 code using the standard library. Define the requested function. Do not include Markdown fences, explanations, tests, or executable input/output code.
