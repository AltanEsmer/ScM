Define eval_lexical(data), which evaluates the expression AST supplied as data and returns its integer result. AST nodes are lists with these forms:
['int', n], ['var', name], ['add', a, b], ['sub', a, b], ['mul', a, b], ['if0', condition, then_expr, else_expr], ['let', name, value_expr, body], ['fn', param, body], ['call', function_expr, argument_expr], and ['letrec', name, param, function_body, body]. Names consist of one to eight lowercase ASCII letters.

Integers use exact arithmetic. add, sub, and mul evaluate their operands strictly from left to right. if0 evaluates its condition and then only then_expr if the result equals zero, otherwise only else_expr. let evaluates value_expr in the old environment and evaluates body with name bound to that value. fn creates a function capturing its lexical environment. call evaluates function_expr and then argument_expr, and evaluates the function body in its captured environment extended with param bound to the argument. letrec binds name to a function with parameter param and body function_body, capturing an environment that includes this same function binding, then evaluates body in that environment. name and param in a letrec differ. New bindings shadow existing bindings. Functions may be passed and returned internally.

The top-level expression is guaranteed closed, type-valid, terminating, and integer-valued. It has at most 250 syntactic nodes, evaluates at most 2000 expression nodes, and has dynamic evaluation nesting at most 200. Every intermediate integer is between -1000000000 and 1000000000 inclusive. Do not mutate data.

Return only Python 3.12 code using the standard library. Define the requested function. Do not include Markdown fences, explanations, tests, or executable input/output code.
