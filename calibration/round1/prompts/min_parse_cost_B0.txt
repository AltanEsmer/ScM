Define min_parse_cost(data). The JSON object data has nonterminals (an integer k, 1 <= k <= 8), start (a nonterminal index), rules, and text. There are at most 30 rules. A rule is [lhs, rhs, cost], where lhs is a nonterminal index, rhs is a list of zero to three symbols, and cost is an integer from 0 through 10. Each symbol is ['N', i] for a nonterminal or ['T', c] for a terminal character c in 'ab'. All nonterminal indices are from 0 through k-1. text contains only 'a' and 'b' and has length at most 24.

A parse is a finite ordered tree rooted at start. Every nonterminal occurrence expands using one rule with that lhs; its children, in order, are that rule's rhs. Terminals are leaves. An empty rhs yields the empty string. The terminal yield must equal text exactly. The cost is the sum of the rule costs over every rule occurrence in the tree. Return the minimum cost as an integer, or None when no finite parse exists. Duplicate rules, empty rules, unit rules, self and mutual recursion, and zero-cost cycles are allowed. Do not mutate data.

Return only Python 3.12 code using the standard library. Define the requested function. Do not include Markdown fences, explanations, tests, or executable input/output code.
